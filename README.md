# MG4
## Devlog
Start() method: Sets the initial starting values when the object spawns.  
Update() method: Runs every frame to continuously move the food.  
_up variable: Acts as a switch (true or false) to control whether the food moves up or down during that frame.  
_timer variable: Tracks how long the food has been moving in one direction. Inside Update(), once it reaches a specific time limit, the timer resets, and the _up variable flips to reverse the movement direction.
